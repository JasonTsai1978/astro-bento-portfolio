*2017 年 1 月，開箱那天。*

這台筆電有段故事。12 吋 MacBook 是蘋果口中「史上最薄、最輕的 Mac」，厚 13.1 mm、重約 0.9 公斤。2016 年改款時推出了玫瑰金，也是 Mac 第一次有這個顏色。當年我特別挑了玫瑰金，送給太太當生日禮物。

後來它在家裡閒置了好幾年。這週，它變成家裡最有用的一台電腦：一台安靜的 Linux 主機，24 小時跑 Claude Code，我用手機就能派工作給它，平日早上還會送半導體新聞摘要給我。

## 為什麼選這台

我想要一個隨時在線、在外面也叫得到的 AI agent，而不是每次都要打開的聊天視窗。家裡的桌機不會一直開著，Windows 更新也會自己重開機。

這台 MacBook 反而剛好：沒有風扇、很省電，而且本來就在家裡。Core m3 加 8 GB RAM 現在看很普通，但沒關係。模型跑在雲端，這台只要負責讓 terminal 一直開著。

<img src="/blog/macbook-rose-gold-open.jpg" alt="第一次打開的 MacBook，注音鍵盤" style="max-height:520px;margin:0 auto;display:block;border-radius:6px" />

*2017 年第一次打開它。快十年後，這副鍵盤只剩 Enter 還有反應。*

## 裝了四次才成功

我清掉 macOS，改裝 Ubuntu Server 24.04 LTS，前後裝了四次：

- **安裝畫面的字小到看不見。** 12 吋 Retina 螢幕解析度太高，換成大號字型才能操作。
- **一個「保險用」的開機參數，反而讓安裝失敗。** 原本想避開 Mac 的 EFI 問題，結果害安裝程式寫不進開機選項。教訓：沒在自己機器上驗證過的修正，不要先加。
- **SSD 裝到一半消失。** Apple 的 NVMe 控制器跑幾分鐘就斷線，這是 NVMe 省電模式太激進的已知問題。加兩個 kernel 參數，讓 SSD 不要進深度睡眠：

```
nvme_core.default_ps_max_latency_us=0 pcie_aspm=off
```

第四次就順利裝完了。唯一留下的怪問題是內建鍵盤只剩 Enter 有反應，不過我本來就不會在它上面打字，所以不影響。

## 怎麼運作

Claude Code 以 remote-control 模式在背景常駐，當掉或重開機都會自己起來。我在手機上打開 Claude App，選這台 MacBook，就能派工作給它，用 4G 在外面也行。它沒有對外開放任何服務，SSH 只限家裡的區網。

它每天固定做兩件事：

- **早上的新聞摘要。** 現在是半導體產業新聞，接下來還會加上 NBA、美國職棒、中華職棒、F1 等運動新聞。工作之外，這些才是我每天真正會追的。程式先從新聞網站的 RSS 抓資料，再交給 Claude 摘要，平日早上 7:30 用 Telegram 推到我手機。摘要時把 Claude 的工具全部關掉，網路上的新聞內容不可信，只能輸出文字的 AI 就不會被誘導去執行指令。
- **每 5 分鐘健康檢查。** 一支單純的 shell script 檢查電源、SSD、磁碟、溫度和 agent 服務，有異常就通知我。電池已經快十年了，電源出狀況我想早點知道。

權限也收得很緊：Telegram bot 只能發訊息、不能收指令；Claude Code 被禁止讀取金鑰和憑證，我先用測試檔驗證過才放心。

至於 email 和行事曆，我目前還不放心讓 AI 碰我個人的帳號。之後也許會另外開一個獨立帳號，先讓它在那裡試試看。

## 心得

**舊電腦當 agent 綽綽有餘。** 開兩個 session，RAM 只用掉約 750 MB，溫度大約 33°C。

**大部分時間都花在 debug。** 裝失敗的那幾次和斷線的 SSD，花的時間遠比設定本身多。每次失敗都記下原因，第四次才會成功。

**這次不是我一個人做的。** 桌機上的 Claude Code 幫我規劃安裝步驟、寫好設定 script，我拍 MacBook 的螢幕回報，它一步一步帶我做。這也是我用 AI 的方式：先在自己的工作上試，留下真的好用的，再帶給團隊。

一份放了好幾年的生日禮物，現在每天早上都在幫我工作。
