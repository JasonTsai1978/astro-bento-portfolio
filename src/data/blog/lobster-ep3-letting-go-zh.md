*「養龍蝦」系列第 3 集。[第 1 集](/blog/lobster-ep1-week-one-zh/)講部署，[第 2 集](/blog/lobster-ep2-march-zh/)講三月的維運，這集講我為什麼收手。*

先講結論：2026 年 9 月中，我把 Zeabur 停掉，龍蝦退租了。不是它不好用，而是我發現自己其實不需要一隻龍蝦。

## 最後一次維修

3/28，我照例請 Claude 幫我查龍蝦的新版本值不值得升。

答案是：新版已經到 2026.3.24，比我用的 3.8 多了 16 個小版本，其中大部分是我用不到的功能。但有一個 CVSS 9.9 的認證繞過漏洞，要升到 3.12 以上才會補起來。結論是該升級了。

這是我最後一次跟 Claude 討論龍蝦的維運。回頭翻對話紀錄，四月到八月，龍蝦幾乎沒有再出現過。

## 我放手的五個原因

**1. 龍蝦能做的事，AI App 陸續都做得到了。** 四月到九月，各家 AI 一直推出新版本。網頁版的 Claude、ChatGPT、Gemini 本身就能上網查資料、整理新聞；加上 Codex、Claude Code 這類工具，很多事根本不需要一隻常駐的龍蝦。

**2. 複雜的事，用 Claude Code 比較快。** 龍蝦是透過 Telegram 下指令，後端還要綁一個付費的 API。簡單的查詢沒問題，事情一複雜，用聊天訊息來回就很卡；牽涉到寫程式，更難交給龍蝦。同樣的事，我打開 Claude Code 直接做，快很多。

**3. 我沒有時間一直幫它升級。** 龍蝦早期版本更新很頻繁，每次升級都可能出狀況，出了狀況就要開 Zeabur、開 Claude，一步一步查問題。第 2 集那些維修，回頭看大多是在追版本。四、五月之後工作變忙，我就沒有再跟上了。說實話，我覺得那些時間有點浪費。

**4. 我其實不需要助理。** 這是最根本的一點。一開始我替龍蝦設計了管家，幫我盯信箱、排行程。但真的用下來，我不需要有人一直看著我的收件匣，替我安排事情。公司的郵件和行事曆，更不可能交給它。

**5. 資料來源不穩。** 我最常用的是每天的股價和產業新聞，但 API 額度用完或被網站擋掉的時候，報告就會出現過期的資訊，或是乾脆找不到資料。對一份「每天早上看一眼」的早報來說，偶爾不準比沒有更麻煩，因為你不知道今天這份能不能信。

## 九月，代管版的龍蝦出現了

九月中，我讀到一篇 Meta 新產品 Muse 的一週心得。Muse 本質上就是代管版的龍蝦：每個人一台專屬的雲端電腦，有長期記憶，還能自己開瀏覽器替你做事，而且不用自己維運。差不多同一時間，xAI 的 Grok Bot 也在做一樣的事。

那位作者的結論是：「AI 助理的價值不在回答問題，在於記得所有的事，直接幫你打雜。」他把銀行帳戶、券商報表、十年的健檢報告都交給它管。

我同意這句話對他成立，但對我不成立。我的工作資料不能交出去，私人生活又沒有那麼多雜事需要代勞。何況 Muse 當時只開放美國。回頭看，我自己的龍蝦裡，管家那條線最後也沒用起來，原因一樣。

## 但我還是需要一台機器

真正讓我放不下的，只有一件事：每天早上的新聞摘要。這是龍蝦做過最有用的工作。

9/30 我問 Claude，有沒有不用自己開主機、也能每天整理 AI 新聞的方法。當時我寫的是：「目前我並沒有可以全天候開機的電腦可以用，之前有訂閱 Zeabur 平台，目前也停用了。」

一週多之後，家裡那台閒置多年的 MacBook 接下了這份工作。

## 留下的，和放下的

| 留下的 | 放下的 |
| --- | --- |
| 每天早上的新聞摘要，用 Telegram 推給我 | 替我盯信箱、排行程的管家 |
| 交接文件：每次收工都更新進度 | 三隻各有人設的 agent |
| 先把權限收好，再讓 AI 動手 | 什麼都想讓 AI 自己摸索 |
| 讓 AI 直接在機器上做事 | 我在兩個視窗之間複製貼上 |

## 一句平反

不過，我到現在還是覺得，用 Telegram 指揮一個 AI agent，未來會變成很常見的事。龍蝦的方向沒有錯，也許只是我玩得早了一點，後來又沒繼續跟上。
